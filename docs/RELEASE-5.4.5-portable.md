# CorporateAgent 5.4.5 Portable

Переносимая версия на основе **CorporateAgent v5.4.5-fixes**. Java и библиотеки включены; установка Java не требуется.

## Скачать

Все файлы находятся в **Assets** этого релиза:

| Платформа | Файл |
| --- | --- |
| Windows 10/11 x64 | `CorporateAgent-5.4.5-Portable-Windows-x64.zip` |
| macOS, Apple Silicon | `CorporateAgent-5.4.5-Portable-macOS-AppleSilicon.tar.gz` |
| macOS, Intel | `CorporateAgent-5.4.5-Portable-macOS-Intel.tar.gz` |

К каждому архиву приложен `.sha256`. Автоматические GitHub **Source code** предназначены для разработчиков.

## Быстрый запуск

1. Распакуйте весь архив в доступную для записи папку.
2. Windows: `run.bat`. Mac: `Start.command`.
3. Откройте «Настройки» → «Модель», введите пароль раздела `1234`, укажите провайдера и свой ключ API.
4. Нажмите «Проверить подключение», затем «Сохранить».
5. Создайте чат или проект.

Для завершения используйте `Stop.bat` / `Stop.command`. Для переноса сохраняйте всю папку вместе с `data`; при смене ОС используйте архив для новой ОС и переносите только данные.

## Что входит

- Windows x64, macOS ARM64 и macOS x86_64 со встроенной Java 21.
- Браузерный интерфейс, чаты, проекты, навыки, инструменты, SQLite и работа с документами.
- Автоматическое обновление внутренних путей после переноса `data`, с копией метаданных перед изменением.
- Инструкции `INSTALL.md` и `USER_GUIDE.md` внутри каждого архива.
- Чистая папка данных: история и ключи автора не включены.

## Проверка и ограничения

- Прошли штатные тесты приложения: AgentHeadlessTest, SmokeCoreTest, WebFlowTest, PresetRecoveryTest, TemplateAcceptance, YandexSetupTest и ScenarioRulesTest; PackageProbe проверил загрузку производственного JAR.
- Проверены Windows-запуск со встроенной Java, повторный запуск, авторизация локального API, веб-ресурсы, перенос чатов и путей баз, чтение перенесённых баз и завершение работы.
- Отдельно проверено преобразование путей Windows/macOS с сохранением внешних ссылок и обычного текста.
- Архивы проверены на целостность; Java для Mac сверена с SHA-256 официальных дистрибутивов Temurin.
- **На реальных Mac запуск не проверен.** Отдельные чистые Windows 10/11 также не использовались. Сборка приложения не проходила отдельную подпись/нотариализацию Apple.
- Тест Яндекса использовал локальный имитатор. Реальный API на компьютере пользователя требует отдельной настройки и проверки.
