# Запуск CorporateAgent 5.4.5 Portable

Устанавливать приложение, Java, Python или Node.js не нужно. Java и библиотеки уже входят в каждый архив. Интерфейс открывается в браузере на этом же компьютере.

## 1. Выберите архив

Откройте [релиз v5.4.5 Portable](https://github.com/chikilevsergei-byte/CorporateAgent-v3/releases/tag/v5.4.5-portable) и скачайте файл из **Assets**:

| Компьютер | Архив | Запуск | Завершение работы |
| --- | --- | --- | --- |
| Windows 10/11, Intel или AMD, 64 бита | `CorporateAgent-5.4.5-Portable-Windows-x64.zip` | `run.bat` | `Stop.bat` |
| Mac с Apple Silicon, M1–M5 | `CorporateAgent-5.4.5-Portable-macOS-AppleSilicon.tar.gz` | `Start.command` | `Stop.command` |
| Mac с процессором Intel | `CorporateAgent-5.4.5-Portable-macOS-Intel.tar.gz` | `Start.command` | `Stop.command` |

На Mac тип процессора указан в меню Apple → «Об этом Mac». Сборка Windows предназначена для x64; Windows ARM и 32-битная Windows не проверены.

Не выбирайте автоматически добавленные GitHub архивы **Source code** для обычного запуска: это исходники для разработчика.

## 2. Распакуйте и запустите

### Windows

1. Нажмите правой кнопкой по ZIP → «Извлечь всё».
2. Сохраните распакованную папку в доступное для записи место, например «Документы» или на флешку.
3. Откройте папку и дважды нажмите `run.bat`.
4. Дождитесь открытия браузера. При первом запуске приложение создаст папку `data` и встроенные базы методологий.

Не запускайте программу прямо внутри ZIP. Права администратора не требуются. Если Windows показывает предупреждение о загруженном файле, сначала проверьте источник и SHA-256 архива. Если запуск ограничен политикой организации, обратитесь к администратору.

### macOS

1. Распакуйте соответствующий `.tar.gz` в Finder. Не переносите отдельные файлы из его папки.
2. Поместите всю папку в доступное для записи место.
3. Откройте `Start.command`. Должны открыться Terminal и браузер.
4. Если Finder не запускает командный файл, откройте Terminal, введите `/bin/bash `, перетащите `Start.command` в окно Terminal и нажмите Enter.

Сборка приложения не проходила отдельную подпись и нотариализацию Apple. Если macOS блокирует загруженные файлы, проверьте источник и контрольную сумму и разрешите конкретный запуск через штатные настройки «Конфиденциальность и безопасность», если такое действие доступно. Не отключайте Gatekeeper целиком. На управляемом Mac может потребоваться помощь администратора.

## 3. Подключите модель

1. Нажмите **«Настройки» → «Модель»**.
2. Введите пароль раздела: **`1234`**. В этой версии он фиксированный; это блокировка от случайного изменения настроек, а не защита файлов приложения.
3. Выберите провайдера и заполните поля из [руководства пользователя](USER_GUIDE.md#подключение-модели).
4. Нажмите **«Проверить подключение»**, затем **«Сохранить»**.
5. Создайте чат и отправьте короткий пробный запрос.

Для ответов модели нужен доступ к выбранному API и действующий ключ. Ключи в релиз не включены. Возможность запуска интерфейса без интернета не означает, что облачная модель работает офлайн.

## Завершение работы и перенос

1. Дождитесь окончания ответа модели или остановите запрос в интерфейсе.
2. Запустите **`Stop.bat`** или **`Stop.command`** из папки этой копии приложения. Закрытие вкладки браузера само по себе сервер не завершает.
3. После успешного завершения скопируйте **всю папку приложения**, включая `data`, на другой компьютер.
4. На другом типе ОС распакуйте соответствующий новый архив, затем скопируйте в него папку `data` из остановленной старой копии. Не переносите Windows Java на Mac или наоборот.
5. Запустите новую копию. Внутренние пути к базам и файлам в `data` будут обновлены. Перед обновлением путей сохраняется копия JSON-метаданных в `data/backups/portable-relocation-*`.

Не используйте одну папку данных одновременно в двух запущенных экземплярах. Внешние файлы и базы, подключённые за пределами `data`, автоматически не переносятся: скопируйте их отдельно и заново укажите путь.

Папка `data` содержит историю и настройки, в том числе сохранённые ключи API. Передавать её другим людям следует только намеренно. Для чистой раздачи используйте исходный архив релиза.

## Проверка контрольной суммы

Рядом с каждым архивом опубликован файл `.sha256` с ожидаемой суммой.

Windows PowerShell:

```powershell
Get-FileHash .\CorporateAgent-5.4.5-Portable-Windows-x64.zip -Algorithm SHA256
```

macOS, Terminal из папки загрузки:

```bash
shasum -a 256 CorporateAgent-5.4.5-Portable-macOS-AppleSilicon.tar.gz
```

Для Intel подставьте имя Intel-архива. Сравните результат со скачанным `.sha256`.

## Если приложение не запускается

| Симптом | Действие |
| --- | --- |
| Нет `jre` или `dist` | Повторно распакуйте весь архив, сохранив структуру папок. |
| Mac сообщает о неверной архитектуре | Скачайте архив для своего процессора. |
| Папка доступна только для чтения | Перенесите приложение в доступную для записи папку. |
| Браузер закрыли, а сервер остался | Повторно запустите `run.bat` или `Start.command`: откроется работающий экземпляр. |
| Ошибка при старте Java | Проверьте `launch-logs`; не публикуйте журнал без проверки на ключи и приватные сведения. |
| Интерфейс работает, модель не отвечает | Используйте «Проверить подключение», проверьте ключ, провайдера, модель и сетевой доступ. |

## Границы проверки

Локально проверены Windows-запуск со встроенной Java, повторный запуск, завершение, перенос чатов и внутренних баз в другую папку, включая пути с пробелами и кириллицей. Отдельные чистые компьютеры с Windows 10 и Windows 11 не использовались.

Для macOS проверены состав архивов, архитектуры Java и наличие SQLite-библиотек для ARM64/x86_64, права исполнения запускателей и контрольные суммы. **Фактический запуск на Mac не проверен.** Совместимость с каждой версией macOS и каждой моделью M1–M5 не подтверждена отдельным испытанием.
