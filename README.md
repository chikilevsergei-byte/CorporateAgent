# CorporateAgent — помощник руководителя проектов

**Актуальный релиз: 5.4.5 Portable**
Работает локально, открывает интерфейс в браузере и подключается к выбранной модели по API.

## Скачать и запустить

**[Открыть релиз и скачать готовую сборку](https://github.com/chikilevsergei-byte/CorporateAgent-v3/releases/tag/v5.4.5-portable)**

| Компьютер | Скачать | Запуск |
| --- | --- | --- |
| Windows 10/11 x64 | [ZIP](https://github.com/chikilevsergei-byte/CorporateAgent-v3/releases/download/v5.4.5-portable/CorporateAgent-5.4.5-Portable-Windows-x64.zip) | `run.bat` |
| Mac Apple Silicon, M1–M5 | [TAR.GZ](https://github.com/chikilevsergei-byte/CorporateAgent-v3/releases/download/v5.4.5-portable/CorporateAgent-5.4.5-Portable-macOS-AppleSilicon.tar.gz) | `Start.command` |
| Mac Intel | [TAR.GZ](https://github.com/chikilevsergei-byte/CorporateAgent-v3/releases/download/v5.4.5-portable/CorporateAgent-5.4.5-Portable-macOS-Intel.tar.gz) | `Start.command` |

1. Скачайте архив под свой компьютер и распакуйте **полностью** в доступную для записи папку.
2. Запустите указанный файл. Установка Java, Python и Node.js для основного приложения не требуется.
3. Откройте **«Настройки» → «Модель»**, пароль раздела — **`1234`**. Выберите провайдера, введите свой ключ и параметры модели.
4. Нажмите **«Проверить подключение»**, затем **«Сохранить»**.
5. Создайте чат или проект.

Для завершения работы используйте `Stop.bat` / `Stop.command`. Для облачной модели нужны интернет и действующий доступ к API. Ключи в архивы не включены. Фиксированный пароль раздела не шифрует данные.

## Возможности

- Чаты с моделью и сохранение истории.
- Проекты с базой данных и семью рабочими чатами: паспорт, риски, план, статус, протоколы, подготовка к УК и сценарий проверки страницы Confluence.
- Подключение DeepSeek, Яндекс AI Studio, Alibaba Qwen и совместимых API через настройки.
- Встроенные методологии, навыки, инструменты и заметки.
- SQLite: просмотр, операции с данными, импорт/экспорт и резервные копии.
- Извлечение текста из документов, создание PPTX и XLSX, работа с включёнными шаблонами.
- Перенос папки `data` между сборками для разных ОС с обновлением внутренних путей.

Пользовательские Python/shell-инструменты могут требовать внешние программы, не входящие в релиз. Названия сценариев не означают, что внешние корпоративные системы уже подключены.

## Данные и ограничения

- Данные находятся в `data` рядом с приложением. При переносе внутри одной ОС копируйте всю папку приложения; при смене ОС используйте новую сборку и перенесите `data` после остановки старой копии.
- Сохранённые API-ключи входят в пользовательскую папку `data`; не передавайте её как чистый дистрибутив.
- Windows-запуск и перенос данных проверены локально. Отдельные чистые Windows 10/11 не использовались.
- **Запуск на реальных Mac не проверен.** Проверены архивы, архитектуры Java/SQLite и права исполнения запускателей. Приложение отдельно не подписано/не нотариализовано Apple.
- Реальное подключение к вашему провайдеру проверяется кнопкой «Проверить подключение». Локальные тесты не заменяют эту проверку.
