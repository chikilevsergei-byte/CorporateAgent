# 🤖 CorporateAgent v3

**ИИ-ассистент руководителя проектов** — десктопное приложение на **Java (Swing)**, полностью переписанное с CorporateAgent v2 (Python/Streamlit). Работает с **DeepSeek** через API. Поддерживает **портабельный запуск** (без установки Java у конечного пользователя).

---

## ✨ Возможности

- 💬 **Чат с ИИ** — история сообщений, авто-названия чатов, контекст навыков/инструментов/БД.
- 🧠 **Навыки** — добавление/редактирование/удаление навыков, которые агент учитывает при ответах.
- 🔧 **Инструменты** — управление инструментами, доступными агенту.
- 🗄️ **Базы данных (SQLite)**:
  - Создание БД из SQL-схемы (вручную или **генерация схемы ИИ** по описанию).
  - Просмотр таблиц и данных.
  - Выполнение произвольных SQL-запросов.
  - **Импорт CSV** (добавление или обновление записей).
  - **Экспорт в SQL** и **резервное копирование**.
  - **Визуализация** данных (столбчатые диаграммы).
  - Журнал операций с БД.
  - **Автообновление БД** — агент сам генерирует SQL из ответов и выполняет его.
- 📄 **Работа с файлами**:
  - Чтение: TXT, MD, CSV, HTML, DOCX, PDF, XLSX, PPTX.
  - Создание: **PPTX** (презентации) и **XLSX** (Excel-таблицы) по запросу.

## 🚀 Быстрый старт (для разработчика)

### 1. Установите JDK
Нужен **JDK 8+** (не только JRE), т.к. требуется компилятор `javac`. Убедитесь, что `javac` доступен в PATH:
```bat
javac -version
```

### 2. Положите библиотеки в `lib\`
Для полного функционала (SQLite, DOCX/PDF/XLSX/PPTX) положите в папку `lib\`:
- `sqlite-jdbc-*.jar` — SQLite
- `poi-*.jar`, `poi-ooxml-*.jar`, `poi-ooxml-schemas-*.jar`, `xmlbeans-*.jar`, `commons-compress-*.jar`, `commons-io-*.jar`, `commons-collections4-*.jar`, `log4j-api-*.jar` — DOCX/XLSX/PPTX
- `pdfbox-*.jar`, `fontbox-*.jar` — PDF

> Без этих библиотек приложение запустится, но функции БД и чтения/создания файлов будут недоступны (появятся понятные сообщения об ошибках).

### 3. Настройте `config.json`
```json
{
  "api_key": "ВАШ_API_КЛЮЧ_DEEPSEEK",
  "model": "deepseek-chat",
  "temperature": 0.1,
  "max_tokens": 4000
}
```

### 4. Соберите и запустите
```bat
build.bat     :: компилирует и собирает dist\CorporateAgent.jar
run.bat       :: запускает приложение
```

## 📦 Портабельный дистрибутив (без установки Java)

Для конечного пользователя, у которого **нет Java**, подготовьте портабельную версию:

### Шаг 1. Соберите jar
```bat
build.bat
```

### Шаг 2. Подготовьте портабельную папку
```bat
prepare_portable.bat
```
Скрипт создаст `dist\CorporateAgent_portable\` со структурой:
```
CorporateAgent_portable/
├── jre/                    # встроенная Java Runtime
├── lib/                    # библиотеки
├── CorporateAgent.jar      # приложение
├── config.json             # настройки
├── databases/ backups/ output/
└── Start.bat               # запуск одним кликом
```

> Если скрипт не нашёл JRE автоматически, отредактируйте переменную `JRE_SOURCE` в `prepare_portable.bat` или вручную скопируйте папку JRE (например, из `C:\Program Files\Java\jre1.8.0_471`) в `dist\CorporateAgent_portable\jre`.

### Шаг 3. Запуск у пользователя
Пользователь просто открывает папку и запускает **`Start.bat`** — установка Java не требуется.

## 🔧 Технические детали

- **Язык**: Java 8 (Swing, входит в JRE — не требует внешних зависимостей для GUI).
- **DeepSeek API**: `HttpURLConnection` из JDK (OpenAI-совместимый формат), без внешних HTTP-библиотек.
- **JSON**: собственный парсер/сериализатор на чистой Java (без зависимостей).
- **SQLite**: через `sqlite-jdbc` (jar в `lib\`).
- **Данные**: JSON-файлы рядом с приложением (`chats.json`, `skills.json`, `tools.json`, `databases.json`, `db_logs.json`).
- **Фоновые задачи**: `SwingWorker` — интерфейс не зависает при обращении к API.
